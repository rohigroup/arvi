# Arvi Hub

Portal público de enlaces de Arvi y landing comercial de Arvi Agente IA.

## Rutas

- `/` — hub móvil para usar como enlace principal en Instagram.
- `/agente` — landing comercial de Arvi Agente IA.
- `/salones` — landing ARVI para salones de belleza.
- `/firmas-contables` — landing ARVI para firmas contables.
- `/contadores` — landing ARVI para contadores independientes.
- `/consultorios` — landing ARVI para consultorios.
